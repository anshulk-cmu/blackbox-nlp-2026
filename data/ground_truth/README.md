# Ground-truth addition dataset

`addition_2digit.csv` — the mathematical ground truth for the project's core task.
Every ordered pair `(a, b)` with `a, b ∈ [0, 99]`: 100 × 100 = **10,000 problems**.
Generated by [`../../src/data/build_ground_truth.py`](../../src/data/build_ground_truth.py)
(deterministic, standard-library only).

This file holds **only the arithmetic facts** — no prompts and no model outputs. The
next step (LLM answers + activation extraction) consumes it but does not modify it.

## Schema

| column      | type | meaning                                                   |
|-------------|------|-----------------------------------------------------------|
| `id`        | int  | row index `0..9999`, equal to `a * 100 + b`               |
| `a`         | int  | first operand, `0..99`                                    |
| `b`         | int  | second operand, `0..99`                                   |
| `sum`       | int  | correct answer `a + b`, `0..198`                          |
| `n_carries` | int  | column carries in schoolbook addition, `0..2` (difficulty)|

Regenerate at any time:

```bash
python src/data/build_ground_truth.py
```
